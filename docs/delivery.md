本版完成 Java 后端、同源管理界面、HTTP 无人机模拟器和两机构 Fabric 开发网络的业务闭环。委托方创建任务，运营商多机执行与上传，平台异步定版并存证，复核人员通过或退回，审批人员按指定版本授权，最后核验文件及完成任务。Fabric 只提供摘要登记与查询，业务控制由 Java 执行。

交付标识用于记录本次工作区版本，不代表已创建 Git tag、提交或对外发布。当前公开文件逐项摘要保存在本次 `source-manifest.json`；本地秘密、运行数据和构建输出不属于公开源码交付。

完整部署使用 Linux x86_64、JDK 21，按根 README 初始化本机随机凭据、构建应用/链码、启动依赖并创建开发通道。初始化完成后，日常运行入口是：

```bash
docker compose --env-file .env -f deploy/compose.yml up -d --wait --wait-timeout 240
python3 deploy/fabric/network.py up
python3 deploy/scripts/run-backend.py --ledger
```

浏览器访问 `http://127.0.0.1:8080/`。既有账号密码位于本机 `.local/demo-credentials.json`；首次部署须先按 README 运行 `--demo --ledger` 完成演示账号初始化。Maven 和启动器都需要选定 JDK 21；Spring Boot 不会自动读取 `.env`，请使用项目启动器。

自动新建一组演示可执行 `python3 deploy/scripts/run-demo.py`，会启动自己的应用并保留新成果。先停止其他项目后端和探针，保持依赖运行；读取既有成果则按演示文档指定原 `runId` 和 `--recheck`，注意主项目与隔离副本各有独立环境。完成任务不改回执行中，授权自然到期按到期后的权限复查，不为展示而重写旧结果。

## 6. 已知限制与完成结论

- 设备通过 HTTP 模拟；不含真实飞控、编队、路径规划或自动缺陷识别。
- 单实例应用、单 Orderer 与开发证书/CaaS 网络用于本地演示；生产高可用、证书轮换和公网部署未验收。
- 摘要一致证明文件与登记版本一致，不证明现场、位置或声称时间真实；链上主体是机构应用，链外元数据不逐项上链。
- 撤销阻止签发新下载地址；已签发地址可在原期限内使用，最长受 300 秒及授权剩余时间约束。
- 查询链不可用时保留 UNKNOWN 并退避；幂等、租约和补偿提供可恢复业务结果，不承诺跨系统严格 exactly-once。
- 性能来自同机短时、小数据集实测；17 MiB 样例是带合法填充的 16×16 PNG，不代表大图解码；不能外推生产 TPS/SLA。
- 部署在同一 Linux amd64 主机复用已固定的镜像/归档/依赖缓存；未执行新操作系统、冷网络安装或跨平台复现。
- 清理功能需要显式启用 `--cleanup`；普通启动不自动删除历史文件。正式账本登记和安全审计追加保留。
